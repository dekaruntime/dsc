# Contributing

`main` is protected. Do not push commits to it.

1. Branch from `main`.
2. Open a pull request.
3. Wait for the **Rust tests** check.
4. Merge with a **merge commit** (squash and rebase are disabled, same as deka).

Release is a tag after the bump PR is on `main`. See [VERSIONING.md](VERSIONING.md)
and [PUBLISH.md](PUBLISH.md).
